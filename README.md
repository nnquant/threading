# Threading

**多个组织、多个策略项目、几十条并行的策略线，一眼看清哪条线该推一把。**

Threading 是使用 **Rust + Tauri 2 + React** 构建的本地桌面工具，按「组织 → 策略项目 → 策略线」组织工作。每条策略线有研发阶段、投入状态、山丘位置、下一步和完整的记录时间线；焦点视图跨所有组织列出逾期的下一步、等待太久的线、停滞的线和缺少下一步的线。数据保存在本机 SQLite 中，没有账户和云端。

设计思路与调研见 [设计说明](docs/design.md)。

## 功能

- **焦点**：七天内到期的下一步（逾期标红）、等待中的线及等待天数、超过设定天数未推进的线、缺少下一步的线、有风险或偏离的项目；进行中的线超过上限时提醒先搁置一些。勾选即完成，可撤销。
- **策略线**：阶段（构想、研究、回测、模拟、实盘、退役）与状态（进行中、等待、搁置、已结束）分开记录；优先级、标签、等待对象、关键指标（夏普、年化、回撤等）、Markdown 说明。
- **子策略线**：任何一条线都能分出子策略线（一个板块、一组参数、一个变体），子策略线还能再分，层级不限。列表和线程图按树排列、可以折叠，线程图里子策略线从上级的线上分出来；推进子策略线也算推进上级，上级有进行中的子策略线时不再提醒它缺少下一步。移到别的项目或删除时整棵子树一起处理。
- **山丘图**：借鉴《Shape Up》，左半边是“还在摸索”，右半边是“只剩执行”。在项目页拖动圆点或在详情里拖动滑块更新位置。
- **下一步**：每条线的第一条未完成待办就是它的下一步，可设截止日期、拖动排序。
- **记录时间线**：笔记、决策、结果；阶段、状态、所属项目的变更自动记录。项目层面可写带健康度的进展。
- **记录编辑器**：写记录的框右上角可以把正在写的内容带到单独的编辑器标签页里继续写。编辑器所见即所得：标题、粗体、列表、待办、引用、代码块、表格、链接和图片，也可以直接输入 Markdown 语法（`## `、`- `、`[] `、`**粗体**` 等）。截图可以直接粘贴或拖进来，图片保存在数据目录的 `images` 文件夹里。草稿自动保存在本机，关闭窗口也不会丢。已有的记录在编辑时也能转到编辑器里改。
- **标签页**：焦点、全部策略线、周回顾和组织页在第一个标签页里切换；每个项目、每份草稿各占一个标签页，切换时保留各自打开的策略线和滚动位置，重启后恢复。
- **列表与看板**：全部策略线按项目、阶段、状态或优先级分组；看板按阶段排列，拖动卡片即可换阶段。
- **线程图**：每条策略线画成一根随时间延伸的线。粗细表示阶段，虚线表示等待，点线表示搁置，久未推进的线会逐渐变淡；笔记、决策、结果和换阶段是线上的结，今天右侧是待办截止日和项目目标日期。可看最近 4 周、12 周或半年。
- **周回顾**：逐条过一遍进行中和等待中的线，确认阶段、山丘位置和下一步，标记已回顾。
- **命令面板**：右上角的搜索框或 `Ctrl+K`，搜索策略线、项目、组织或执行命令。
- **自动备份**：每天第一次打开时备份到数据目录，保留最近 14 份；设置里可立即备份。

## 安装

### Windows x64

在 [Releases](https://github.com/nnquant/threading/releases/latest) 下载 **0.1.0** 版：

- **安装版**：下载 `Threading_0.1.0_x64-setup.exe`，运行安装程序。
- **便携版**：下载 `Threading_0.1.0_windows_x64_portable.zip`，解压后运行 `Threading.exe`，请保留同包的 `LICENSE`。

运行需要 Windows 10/11 和 Microsoft Edge WebView2 Runtime。应用未进行代码签名，首次运行时 Windows 可能提示来自未知发布者。安装版和便携版读写同一个数据目录（见下文「数据」）。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 搜索与命令 | `Ctrl+K` |
| 新建策略线 | `N` |
| 在打开的策略线下新建子策略线 | `Shift+N` |
| 焦点 / 全部策略线 / 周回顾 | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` |
| 列表中切换策略线 | `↑` / `↓` |
| 折叠或展开子策略线，回到上级 | `←` / `→` |
| 关闭详情、弹窗 | `Esc` |
| 发布记录、保存说明 | `Ctrl+Enter` |
| 关闭当前标签页 / 切换标签页 | `Ctrl+W` / `Ctrl+Tab`、`Ctrl+Shift+Tab` |
| 编辑器里插入链接 | `Ctrl+K` |

输入框内的按键保留正常输入行为。

## 数据

数据库位于 `%APPDATA%\com.threading.desktop\threading.db`，备份在同目录的 `backups` 文件夹，记录里插入的图片在同目录的 `images` 文件夹（备份只包含数据库内容，图片文件需要连同文件夹一起备份）。状态栏显示当前数据文件，点击可在文件夹中打开。设置环境变量 `THREADING_DATA_DIR` 可改用其他目录。

删除组织、项目或策略线会连同下属内容（包括全部子策略线）永久删除，操作前会确认，但记录里用过的图片文件会留在 `images` 文件夹；不再推进的线建议改为「已结束」，不再合作的组织建议归档。

示例数据没有界面入口：在右上角的搜索框输入 `ENABLE_SAMPLE_DATA` 后回车，会添加三个带几个月历史的示例组织（侧栏里标着「示例」）；输入 `DISABLE_SAMPLE_DATA` 后回车，确认后删除这些示例组织及其下的全部内容，其他数据不受影响。

## 从源码运行

需要 Node.js 22+、npm、Rust（仓库通过 `rust-toolchain.toml` 固定 **1.95.0**），以及 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)。Windows 需要 Visual Studio C++ Build Tools 和 WebView2。

```powershell
npm ci
npm run desktop
```

仅查看界面：

```powershell
npm run dev
```

打开 `http://127.0.0.1:1430`。浏览器预览使用示例数据，改动只保存在该浏览器中。

构建 Windows 安装包：

```powershell
npm run desktop:build
```

## 测试

```powershell
npm test
npm run build
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

前端测试覆盖状态合并、焦点与回顾计算、策略线历史的还原与线程图时间轴、预览存储的契约规则、命令名与 Rust 注册命令的一致性，以及主要界面流程；Rust 测试覆盖校验、事件生成、级联删除、迁移、备份轮换和真实 IPC 调用。
